## 📦 Asset Overview

### 1. Vector Logos (SVG)
- **[`wavelet-logo.svg`](./wavelet-logo.svg)**: Master logo with squircle dark background (`#0D0D0F`) and brand red mark (`#FA2D48`). Best for app representations, splash screens, and vector artwork.
- **[`wavelet-logo-mark-red.svg`](./wavelet-logo-mark-red.svg)**: Standalone red Wavelet mark on a transparent background. Scalable to any dimension.
- **[`wavelet-logo-mark-white.svg`](./wavelet-logo-mark-white.svg)**: Standalone white Wavelet mark on a transparent background. Designed for headers, navigation bars, and dark mode UIs.
- **[`wavelet-favicon.svg`](./wavelet-favicon.svg)**: Optimized browser and web app favicon.

### 2. Master App Icons (PNG)
- **[`wavelet-icon-1024.png`](./wavelet-icon-1024.png)**: 1024x1024 master app icon (RGBA with transparency).
- **[`wavelet-icon-512.png`](./wavelet-icon-512.png)**: 512x512 Google Play Store and app marketplace icon.
- **[`wavelet-icon-256.png`](./wavelet-icon-256.png)**: 256x256 high-density web/social icon.
- **[`wavelet-icon-128.png`](./wavelet-icon-128.png)**: 128x128 UI/extension icon.
- **[`wavelet-logo-original.png`](./wavelet-logo-original.png)**: Original repository showcase icon (1254x1254).

### 3. Transparent Marks (PNG)
- **[`wavelet-mark-red-1024.png`](./wavelet-mark-red-1024.png)** / **[`wavelet-mark-red-512.png`](./wavelet-mark-red-512.png)**: Transparent PNGs of the red Wavelet symbol.
- **[`wavelet-mark-white-1024.png`](./wavelet-mark-white-1024.png)** / **[`wavelet-mark-white-512.png`](./wavelet-mark-white-512.png)**: Transparent PNGs of the white Wavelet symbol.

### 4. Native Application Bundles
- **[`wavelet-app-icon.icns`](./wavelet-app-icon.icns)**: macOS application icon bundle (multi-resolution 16px to 1024px).
- **[`wavelet-app-icon.ico`](./wavelet-app-icon.ico)**: Windows application icon bundle (multi-resolution 16px to 256px).

### 5. Media & Display
- **[`wavelet-tv-banner.png`](./wavelet-tv-banner.png)**: Android TV / Leanback landscape banner (1024x576).
